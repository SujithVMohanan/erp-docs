# Sales Calculations

Authoritative totals: [calculation engine](../platform/calculation-engine.md). Selling price lists, volume breaks, promotions, then optional manual override with explanation.

Tax inclusive/exclusive per company/tax rule. Header charges (shipping) after lines. Round-off at grand total.

Preview: `POST /api/v1/calculations/preview` with `document_type = sales_order` (or invoice). Save recalculates anyway.
