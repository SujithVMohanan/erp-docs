# Purchase Calculations

All amounts from the [calculation engine](../platform/calculation-engine.md). Buying **price lists** and vendor-specific prices apply. Frontend preview is non-authoritative.

Landed cost (freight, duty) is a separate allocation onto receipts for inventory value; it does not silently change a posted vendor bill total.

TDS/withholding: calculated on bill when vendor/tax category requires it; stored on header `withholding_total`.
